# Whisper Box

Para transcrever, siga a seção “Para agentes” do README. Para alterar o projeto (motor, painel, ajudante de host), siga o AGENTS.md. Para resumo, ata, decisões ou tarefas de uma reunião transcrita, use a skill `whisper-box-analise` (`.claude/skills/`). O painel web local (`python whisper-box.py painel`) é a interface do humano; não o suba por conta própria.
